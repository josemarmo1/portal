Editor de Orçamentos

Sistema web desenvolvido para uso interno com o objetivo de automatizar a organização e separação de solicitações de orçamento por equipamento.

Sobre o projeto

O Editor de Orçamentos foi desenvolvido a partir de uma necessidade real do processo interno de trabalho.

A ferramenta permite inserir uma solicitação de orçamento e realizar a separação das informações de acordo com os equipamentos envolvidos, facilitando a organização dos itens e o encaminhamento dos pedidos aos fornecedores.

Objetivo

O principal objetivo do projeto é reduzir o trabalho manual na organização dos pedidos de orçamento, tornando o processo mais rápido, padronizado e organizado.

Funcionamento

O usuário insere o pedido recebido no sistema.

A aplicação processa as informações e organiza os itens de acordo com cada equipamento identificado.

Após a separação, os orçamentos podem ser organizados e encaminhados aos respectivos fornecedores.

Principais funcionalidades

Inserção de pedidos em texto.

Separação dos itens por equipamento.

Organização automática das informações.

Geração dos orçamentos.

Cadastro de endereços para utilização nos pedidos.

Interface simples e objetiva.

Utilização diretamente pelo navegador.

Tecnologias

HTML5
